# 📂 **Week 6 – Python**
This week marked the transition from **C to Python**, a high-level language that simplifies syntax and memory management while preserving logical thinking. I learned how to write cleaner, faster, and more expressive code using Python's built-in features and libraries.

## 🛠️ **Execution Examples**

Run any Python file directly:

```bash
python filename.py
```

Run a problem set inside its folder, for example:

```bash
cd problem-sets/dna
python dna.py databases/large.csv sequences/5.txt
```

## 📝 **Notes**

✓ Python automates memory management — no need for `malloc` or `free`.  
✓ Code blocks are defined by indentation, not braces `{}`.  
✓ Lists are dynamic and can store mixed data types.  
✓ Dictionaries act as native hash tables for key-value storage.  
✓ Strings are immutable; operations return new strings.  
✓ Python’s readability makes it ideal for prototyping and learning algorithms.

## ✅ **Summary**

This week emphasized **clarity over syntax**. Python’s simplicity allowed me to focus on **problem-solving logic**, understanding that programming is less about language syntax and more about **how to structure solutions efficiently**.
